# あつまる卓

公開先: https://iruca.tech/lobby/

2026-11-24時点の公開版から独立させたソースリポジトリです。リポジトリへのpushだけでは本番は更新されません。

## 起動・テスト

Node.js 24以上が必要です。

```sh
npm ci
npm run build
npm test
npm start
```

既定URLは `http://127.0.0.1:3190/`。`HOST`・`PORT`・`LOBBY_DB` で待受とSQLite保存先を指定できます。

```sh
npm run build:vps
```

生成する `lobby-vps.tar.gz` はVPS向けです。`deploy/` は設定テンプレートです。サービスのNode実行パスと `RELEASE_ID` を配置先に合わせて置換してください。既存のCaddyサイト内に経路だけを追加し、検証してから読み込みます。DBはリリースの外に保持します。

チンチロ（親回り・親固定・イカサマあり）とハイ＆ローを収録。部屋・資格・持ち点はSQLiteへ保存されます。

## 開発中に重視したポイント

ChatGPTとの企画・実装・調整で扱った内容をまとめています。現行のゲーム種類と起動方法は上記、動作の詳細は各ゲームの実装を参照してください。

- **配信者が参加者を選べる卓にする。** 待機所から配信者が2〜4人を選ぶ構想を起点に、観戦と参加希望を分け、入室・参加希望・指名・再戦・観戦中の出目共有を実装・確認しました。
- **持ち点が尽きても観戦と再参加の導線を残す。** 0点以下のプレイヤーは卓から待機所へ戻り、待機中のアイコンを💸にする方針で調整しました。ホスト3000点、リスナー0点から始める設定も、この参加管理と合わせて検討しました。
- **回線落ちや操作待ちで進行が止まらないようにする。** 自動進行の待ち時間は一律20秒に調整しました。掛け金、サイコロ、次の親への移行など、操作待ちと画面上の残り時間を対応させることが確認点です。
- **CPUの役割を見た目と行動で伝える。** 😈デビルゴッドダイスと🛁風呂キャンセルを用意し、待機所も含めて名前を青字にする調整を行いました。CPUは賭けと投擲を速やかに進め、デビルゴッドダイスは所持点の約3分の1を100点単位で切り上げ、風呂キャンセルは100点・200点から選ぶ方針にしました。
- **試作から継続利用できる構成へ進める。** 初期モックの部屋状態は再起動で消える構成でした。現行版は部屋・資格・持ち点をSQLiteに保存し、リリースの更新とデータの保持を両立する構成になっています。
- **同じ卓で遊べるゲームを増やす。** チンチロの親回り・親固定・イカサマありに加え、ハイ＆ローとシゴロ賽を扱いました。ゲームを追加しても、参加者管理、観戦、再戦の流れがつながることを重視しました。

## 公開物の範囲

ゲームコードと必要な画像・音声を収録しています。本番の部屋データ、アクセスログ、集計結果、認証情報、非公開運用文書は含みません。

ソース・画像・音声の再利用許諾を新たに付与するものではありません。ライセンスは別途定めるまで未設定です。
